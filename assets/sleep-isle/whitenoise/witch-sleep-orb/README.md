# 晚安水晶球

一个使用原生 HTML、CSS 和 JavaScript 制作的沉浸式白噪音网页 Demo。项目无后端、无数据库、无框架，也不需要安装依赖。

## 本地运行

推荐使用以下任一方式启动静态服务器：

- VS Code Live Server；
- 在项目目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

不建议直接双击 `index.html` 作为最终测试方式，因为部分浏览器会限制本地音视频资源的读取或播放。

## 当前功能

- 5 个白噪音分类，每类 2 个真实场景；
- 圆形视频水晶球，视频始终静音；
- MP3 独立播放、暂停与音量控制；
- 15、30、60 分钟睡眠计时；
- 桌面与手机基础响应式布局；
- 素材加载失败时的页面提示与控制台警告。

音频是用户唯一能听到的声音来源。视频只作为水晶球内部的装饰画面，并通过 HTML 属性与 JavaScript 双重强制静音。
