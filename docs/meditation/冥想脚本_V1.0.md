## 1. Release the Day｜放下今天 · 仪式感反刍

今天已经走到这里了。
现在，你不需要再完成什么，也不需要再想清楚什么。
那些还没有回复的消息，没有做完的事情，没有得到答案的问题，都可以暂时留在今天。
轻轻吸一口气。
再慢慢呼出来。
想象你正站在一天的尽头。
手里抱着很多细小的东西：一句没有说出口的话，一个反复回想的瞬间，一件还没有解决的事，一点懊恼，也许还有一点不甘心。
现在，把它们一件一件放下来。
不是丢掉它们。
只是告诉自己：今晚，我不需要继续拿着。
明天的你，会有明天的时间去处理。
现在的你，只需要休息。
再吸一口气。
呼气的时候，想象今天慢慢离开你的身体。
肩膀松一点。
眉头松一点。
牙齿也不要再咬紧。
今天发生过的一切，都已经发生了。
你不需要在脑海里重新经历一次，才能证明它重要。
这一刻，没有什么需要解决。
今天到这里，就可以了。
让夜晚接过剩下的事情。
你只需要慢慢地，回到睡眠里。

## 2. Relax Your Body｜身体扫描 · 最通用的睡前冥想

找一个舒服的位置躺下来。
不需要刻意保持姿势。
让床承接你的重量。
先把注意力放到额头。
如果那里还有一点紧绷，让它慢慢展开。
眼睛周围，也松下来。
你已经不需要再看什么了。
放松下巴。
让舌头自然地落在嘴里。
现在，把注意力移到肩膀。
想象肩膀上的重量，正在一点一点向下沉。
你不需要再撑住今天。
手臂放松。
手掌放松。
每一根手指，都可以安静下来。
慢慢来到胸口和腹部。
不需要改变呼吸。
只是感觉身体正在自己呼吸。
吸气。
身体轻轻起伏。
呼气。
身体又沉回床面。
现在来到腰部、臀部、大腿。
让这些地方变得越来越重。
膝盖放松。
小腿放松。
脚踝放松。
最后，是你的脚。
从头到脚，不需要任何地方保持警觉。
如果还有某个地方没有完全放松，也没有关系。
你不需要努力入睡。
只需要躺在这里。
让身体比刚才更重一点。
再重一点。
床正在托住你。
现在，什么都不用做了。

## 3. Breathe Into Sleep｜慢呼吸 · 快速安静下来

现在，不需要做一个很深的呼吸。
只是慢一点。
轻轻吸气。
一、二、三、四。
稍微停一下。
然后慢慢呼气。
一、二、三、四、五、六。
很好。
再来一次。
吸气的时候，不需要用力。
只是让空气自然地进来。
一、二、三、四。
呼气。
一、二、三、四、五、六。
想象每一次呼气，都在告诉身体：
可以慢下来了。
你不需要强迫自己平静。
也不需要赶走脑海里的想法。
如果一个念头出现，就让它出现。
然后，把注意力轻轻带回呼吸。
吸气。
空气进入身体。
呼气。
身体向下沉。
每一次呼气，都比吸气稍微长一点。
就像海浪来到岸边，然后慢慢退去。
你不需要追着海浪走。
只需要待在这里。
吸气。
呼气。
如果你开始忘记数字，也没有关系。
如果你的注意力已经变得模糊，那很好。
接下来，不需要再数了。
让呼吸自己继续。
慢慢地。
轻轻地。
一口呼吸之后，再一口呼吸。
直到你不再需要听见我的声音。

## 4. Soften the Tension｜渐进式肌肉放松 · 释放身体压力

有时候，身体还紧绷着，我们自己却已经没有注意到。
现在，我们试着把这些力量一点一点还给夜晚。
先轻轻握紧双手。
不用很用力。
感受手掌和手指里的紧张。
保持一下。
然后，松开。
注意松开的那一刻。
再轻轻抬起肩膀，让肩膀靠近耳朵。
停一下。
然后呼气。
让肩膀落下来。
很好。
现在轻轻绷紧双腿。
感受大腿和小腿里的力量。
不用坚持。
然后，全部松开。
让双腿沉进床里。
接下来，轻轻皱一下眉头。
停一下。
再把额头完全放松。
你会发现，有时候我们并不需要"努力放松"。
我们只需要先意识到自己在哪里用力。
然后，允许那股力量离开。
再检查一下身体。
下巴有没有咬紧？
肩膀有没有偷偷抬起来？
手指是不是还抓着什么？
如果有，就松开一点。
不需要一次全部做到。
每一次呼气，都松一点。
每一次呼气，都少用一点力。
现在，身体不需要保护你去面对任何事情。
今晚的任务只有一个。
躺下来。
变得柔软。
然后休息。

## 5. You're Safe Here｜慈心与安全感 · 孤独、焦虑、情绪低落

现在，你已经来到这里了。
这一小段时间，不需要证明自己很好。
也不需要表现得坚强。
如果今天有一点难过，一点孤单，一点不安，都可以留在这里。
你不需要马上把它们变好。
先感觉一下身下的床。
它正在托住你的身体。
感觉被子覆盖在身上。
感觉空气轻轻进入鼻尖，再慢慢离开。
此刻，你就在这里。
这一分钟，没有人要求你回答什么。
没有事情需要马上完成。
你可以安静地存在。
如果脑海里还有声音在说：
"我是不是做得不够好？"
"明天怎么办？"
"为什么我还是这么累？"
不用和它争论。
只是轻轻回答它：
我听见了。
但是现在，我们先休息。
把一只手轻轻放在胸口，或者腹部。
感受自己的温度。
然后在心里对自己说：
我可以慢一点。
我可以不用现在想明白所有事情。
我值得拥有这一晚的休息。
这一刻，我在这里。
这一刻，我是安全的。
夜晚不要求你成为任何人。
所以现在，闭上眼睛。
让自己被床、被黑夜、被这一小段安静轻轻接住。
今晚，你可以休息了。

## 摇杆硬件链路整合（2026-08-16 v2）

### 新增文件
- `backend/gateway/app/static/sleep-isle.html` — 主控页（`/sleep-isle`）：视频层/模块 iframe/AI说话小窗/塔罗卡牌动画/WS 实时驱动/底部调试条
- `hardware/esp32_joystick_firmware/sleep_isle_controller.ino` — ESP32 v2 固件：遥感前/后/下信号 → POST /device/signal
- `backend/gateway/app/static/video/*.mp4` — 7 个占位视频（中文名与规范一致）+ alarm-tone.mp3

### gateway 状态机（crystal_ball.py）
状态：black_standby / onboarding / locked / ai_standby / ai_speaking / module / tarot_cast / alarm / celebrating

| 硬件信号 | 状态转移 |
|---|---|
| 遥感-前 joy_front | 任意 → onboarding（引入.mp4） |
| 遥感-后 joy_back | 任意 → black_standby（强制黑屏，最高优先级） |
| 遥感-下 joy_down | 黑屏/引导态 → locked（锁定.mp4）；闹钟态 → celebrating（欢呼.mp4） |

| 软件信号 | 状态转移 |
|---|---|
| enter_module | ai_standby → module（冥想/白噪音/呼吸/塔罗 iframe） |
| ai_voice speaking=true/false | ↔ ai_speaking（AI说话.mp4 与 AI待机.mp4 互斥；模块内为小窗） |
| tarot_voice_draw | → tarot_cast（转场→卡牌上浮→AI解读，顺序执行） |
| alarm_fire / 停止信号 | → alarm（闹钟.mp4循环+音频）→ celebrating → ai_standby |

### 验证结果（curl 全链路演练）
前→引入 ✓ 下→锁定 ✓ 进模块 ✓ AI说话/停 ✓ 语音抽卡 ✓ 闹钟 ✓ 停止→欢呼 ✓ 后→黑屏 ✓
